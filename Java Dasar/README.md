# Java Dasar - PBO 2026

Lima studi kasus Java dasar disusun mengikuti struktur praktikum:

1. Informasi NIM
2. Perolehan Nilai
3. Perbedaan L dan Kebalikannya
4. Paling Ter
5. Jam Saya

Setiap studi kasus memiliki `App.java`, `input.txt` untuk pengujian lokal, dan folder `test-cases/`.

## Compile lokal

Masuk ke folder studi kasus lalu jalankan:

```bash
javac App.java
java App < input.txt
```

File hasil kompilasi seperti `*.class` tidak boleh di-commit dan sudah dicantumkan pada `.gitignore`.

## Test case

Gunakan file `TC-01.tc` sampai `TC-20.tc` yang disediakan pada praktikum/Delcom. Jangan membuat ulang isi test case secara manual karena expected output harus mengikuti sumber resmi.
